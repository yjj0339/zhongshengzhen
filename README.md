# 众生镇 · 二十四魂的粒子小镇

**线上地址：https://yjj0339.github.io/zhongshengzhen/**

> 手机扫码直达（见 `qr-live.png`）。建议横屏 / 全屏体验，电脑手机均可运行。

一座会呼吸的东方小镇：24 位有名字、有职业、有记忆的"魂火"居民住在里面——铁匠、诗人、更夫、酒馆老板娘、双胞胎、还有一只镇魂猫。它们各自劳作、闲逛、聊天、传谣、在节日里围着喷泉起舞。

你是这座镇的神。**在底部输入一句话**，改写小镇的命运：

- 「办一场丰收祭」—— 全镇聚集广场，烟花升空，魂火绕泉起舞
- 「降一场流星雨」—— 星辰坠落，居民驻足仰望
- 「召唤一场雷雨」—— 魂火惊慌奔回家中，雷电划过天空
- 「湖里有怪物吗」—— 谣言像红色光丝一样在镇里蔓延
- 「让梧桐爷爷和苏小满成为朋友」—— 两团魂火从此牵挂彼此
- 「赐福镇魂猫」—— 它的光会亮上好一阵子

## 特色

- **AI 多智能体**：效用决策 + 路点寻路 + 对话模板 + 记忆与谣言传播网络
- **关系可视化**：居民间的情谊是金色光丝，谣言是红色脉冲
- **昼夜四分钟一轮**：星空、月光、万家灯火、萤火虫、湖面波光
- **神谕系统**：默认离线意图解析开箱即用；也可在设置里填入任意 OpenAI 兼容 API Key（如 DashScope qwen-plus），让大模型实时扮演神明
- **WebAudio 程序化音效**：风声、夜里蟋蟀、丰收祭钟声，零音频素材

## 本地运行

```bash
node tools/server.js 5173
# 打开 http://localhost:5173/
```

## 技术栈

纯 three.js（WebGL2）+ 原生 ES Modules，无构建步骤；粒子魂体 / 关系光丝 / 环境粒子全部为单批次自定义 Shader 点云；程序化生成地形与建筑。
